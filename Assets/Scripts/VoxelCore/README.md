# VoxelCore (Shared Layer)

Пакет базовой логики и структур данных воксельного мира. Является **общим слоем (Shared Core)** для клиента (Unity WebGL / Яндекс Игры) и авторитарного сервера.

---

## 1. Архитектурный контракт и правила изоляции

* **Чистая логика (POCO):** Все классы ядра (`Voxel`, `SubChunk`, `Chunk`, `World`) не наследуются от `MonoBehaviour` и не зависят от рендера Unity (`MeshFilter`, `MeshRenderer`, `Material`).
* **Кросс-платформенность:** Код может без изменений компилироваться и исполняться как внутри Unity (клиент WebGL), так и на выделенном сервере (Unity Headless или C# сервис).
* **События изменений:** Ядро работает в прямом процедурном режиме. Подписчики (мешеры, сетевые брокеры) подключаются на уровне управляющих менеджеров клиента и сервера.

---

## 2. Компоненты ядра

### `Voxel.cs`
* **`BlockType : byte`** — перечисление типов блоков (до 256 типов). `0` зарезервирован под `Air`.
* **`readonly struct Voxel`** — минимальная единица мира, занимающая **1 байт** в памяти.
* Свойства: `IsAir`, `IsSolid`, константа `Voxel.Air`.

### `SubChunk.cs`
* Куб фиксированного размера **$16 \times 16 \times 16$** ($4096$ вокселей).
* Хранилище: плоский одномерный массив `Voxel[4096]`.
* **Зачем нужен подчанк:**
  * **Изоляция мешинга на клиенте:** при изменении 1 блока перестраивается полигональная сетка только затронутого подчанка $16^3$, а не всей высоты мира.
  * **Легковесная сериализация:** передача мира по сети чанками/подчанками по мере приближения игрока.
* Методы: `GetVoxel(x, y, z)`, `SetVoxel(x, y, z, voxel)`.

### `Chunk.cs`
* Вертикальная колонна мира размером **$16 \times 128 \times 16$**.
* Содержит массив из **8 подчанков** `SubChunk[8]` ($8 \times 16 = 128$ блоков по высоте).
* Координаты: `Vector2Int Position` (координаты чанка в двумерной сетке мира).
* Методы: `GetVoxel(localX, localY, localZ)`, `SetVoxel(localX, localY, localZ, voxel)`, доступ к подчанкам `GetSubChunk(index)`.
* **Быстрый доступ:** методы работают напрямую по локальным координатам без избыточных внутренних `if`-проверок. Валидация высоты мира ($Y \in [0..127]$) сосредоточена в `World`.

### `World.cs`
* Фасад и центральная точка входа в воксельный мир.
* Хранит словарь активных чанков `Dictionary<Vector2Int, Chunk>`.
* **Строгий режим модификации:**
  * `SetVoxel(...)` возвращает `bool`. Изменяет воксель **только если чанк уже создан** и $Y \in [0..127]$. Самостоятельно чанки не генерирует.
  * Получение и создание чанков: `GetOrCreateChunk(Vector2Int coord)`.
  * `GetVoxel(...)` безопасно возвращает `Voxel.Air`, если чанк не загружен или $Y$ за пределами допустимого диапазона.
* **Математика координат:**
  * `WorldToChunkCoord(worldX, worldZ)` — корректно транслирует отрицательные координаты (например, мировой $X = -1$ переходит в чанк $-1$, а не $0$).
  * `WorldToLocalCoord(worldCoord)` — переводит мировую координату в диапазон $[0..15]$ (для $X = -1 \to localX = 15$).

## 3. Разграничение ответственности

```
                  +-----------------------------------+
                  |        VoxelCore (Shared)         |
                  |  Voxel, SubChunk, Chunk, World    |
                  +-----------------+-----------------+
                                    |
            +-----------------------+-----------------------+
            |                                               |
+-----------v-----------+                       +-----------v-----------+
|    CLIENT (WebGL)     |                       |        SERVER         |
+-----------------------+                       +-----------------------+
| SubChunkMeshBuilder   |                       | ActionValidator       |
| ChunkView (GameObject)|                       |  (проверка дистанции, |
| Raycast прицела       |                       |   коллизий и читов)   |
| BlockHighlight рамка  |                       | ChunkStreamer         |
| Клиентское предсказание|                       | Генератор ландшафта   |
+-----------------------+                       +-----------------------+
```

1. **Клиент:**
   * Получает сырые подчанки от сервера в локальный `World`.
   * Читает воксели из `SubChunk` и генерирует `UnityEngine.Mesh` (вершины, треугольники, UV).
   * При клике мышью запрашивает у сервера `RequestBreakBlock(x, y, z)`.
2. **Сервер:**
   * Хранит эталонное состояние `World`.
   * Валидирует запрос игрока (дистанция до блока $\le 5$, блок не Bedrock, отсутствие коллизии с телом игрока).
   * Вызывает `World.SetVoxel(...)` и рассылает подтверждение клиентам.
